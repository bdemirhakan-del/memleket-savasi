# Memleket Savaşı

TikTok canlı yayın oyunu. `kur.ps1` ile kurulur, `baslat.bat` ile çalışır.
Ayarlar: `config.json` (tiktokKullanici, turSuresiSaniye, salonAralikSaniye).
Kayıtlar: `stats.json` (şeref salonu). Günlük: `log.txt`.
OBS tarayıcı kaynağı adresi: http://localhost:8080/?yayin=1&ws=ws://localhost:8080
